# Global Macro

This directory is reserved for quantitative global-macro research, including interest rates, inflation, yield curves, monetary-policy expectations, and recession indicators.

## Current status

No executable Python script is currently committed to this directory.

The module is therefore a placeholder in the current repository snapshot and should not be referenced as a runnable dashboard until its implementation is added.

## Intended scope

Future tools in this module may cover:

- central-bank policy rates and expectations;
- inflation and real-rate measures;
- sovereign yield curves and term spreads;
- macroeconomic regime indicators;
- recession and liquidity signals.

Any future implementation should document its exact data sources, outputs, dependencies, and run commands here.
